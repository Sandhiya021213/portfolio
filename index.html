Project

Leave Management System

The Leave Management System is an application designed to streamline the process of requesting and managing leave requests within an organization. The system allows employees to submit leave requests to the Managers, and HR personnel can review, approve, or reject requests and generate reports on leave statistics.

This project uses MySQL as the database, along with HTML, CSS, JavaScript, and Python Flask to provide full CRUD functionality.
